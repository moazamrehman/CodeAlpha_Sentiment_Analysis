# CodeAlpha Task 4 - Sentiment Analysis

## Project Overview

This project performs sentiment analysis on Amazon customer reviews using Natural Language Processing (NLP).

## Dataset

The project uses the Amazon Fine Food Reviews dataset.

## Techniques Used

- Python
- Pandas
- NumPy
- NLTK
- VADER Sentiment Analysis
- Regular Expressions
- Matplotlib
- Seaborn
- WordCloud

## Features

- Text cleaning and preprocessing
- Positive, Negative and Neutral sentiment classification
- Emotion detection
- Sentiment visualization
- Word cloud generation
- Rating vs sentiment analysis
- Sentiment trends over time

## Dataset Columns Used

- Text
- Score
- Time
- Summary

## Results

The project analyzes customer reviews and identifies sentiment patterns that can help businesses understand customer opinions and improve products and services.
